# Vikas Jagtap Technologies — static website

## Files
- `index.html` — page content and sections
- `style.css` — responsive dark theme, cards, animations and layout
- `script.js` — mobile navigation, scroll reveal and email enquiry form

## Preview locally
Open `index.html` in your browser. Google Fonts require an internet connection; system fallbacks are available.

## Before publishing
1. Replace `hello@vikasjagtap.tech` with an email address you actively monitor in both `index.html` and `script.js`.
2. Replace sample project concepts with your real work and links.
3. Verify the services, claims, location and contact details are accurate.
4. Test the contact form on a device with a configured email app. This static form opens a prefilled email; it does not send/store form submissions itself.

## Publish with GitHub Pages
1. Create a GitHub repository, e.g. `vikasjagtap-tech`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Once the site is published, add `vikasjagtap.tech` under the Pages custom domain setting.
6. In your domain registrar's DNS panel, add the DNS records recommended by GitHub Pages. Do not copy arbitrary IPs; use GitHub's current documentation.
7. Enable **Enforce HTTPS** after DNS verification finishes.

Guide: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
